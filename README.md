# 🌱 AGRI-CONTAINER | 都市型スマートアグリ遠隔栽培プラットフォーム

都市型スマートコンテナモニタリングおよび遠隔栽培管理を行うウェブサービスプロトタイプです。  
リアルタイムの時間経過アルゴリズムや定時カメラ監視、1円＝1コインの明確な決済システムを搭載し、リアルなIoT体験と高い操作性を提供します。

---

## 🌟 主な機能

* **🌾 ファーム（遠隔栽培・監視）**
  * 3区画のスマートコンテナを1対1で個別監視
  * 09:00 / 15:00 / 21:00 の1日3回定時カメラ画像同期
  * 実時間に基づいた動的生長計算アルゴリズム（ミニトマト、いちご、サニーレタス、バジル、ベビーリーフ）
  * 土壌水分ステータスの動的検知および自動給水シグナル送信機能
  * 収穫時の現地入場用暗証番号（パスコード）自動発行
